# 文档索引

本目录汇总「小灵」的产品定位、参考资料、实现取舍和验证证据。`outputs/` 是历史调研产物目录，不纳入版本控制。

## 阅读顺序

1. [需求汇总](requirements.md)：说明小灵为什么从连接能力扩展为个人 Agent 应用，以及当前阶段的边界。
2. [参考资料来源](reference-sources.md)：列出调研来源、参考项目类型和当前工程证据。
3. [实现说明](implementation-notes.md)：说明 Android App 的模块拆分、请求行为、会话上下文、流式输出和存储取舍。
4. [验证报告](verification-report.md)：记录当前包名、应用展示名、构建、签名、安装和真机启动结果。
