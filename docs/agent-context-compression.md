# Agent 上下文提取压缩

第 287 阶段第三片，接在 [输入快照](agent-context-snapshot.md)之后。当前实现是确定性提取压缩，不调用模型生成语义摘要。下一片才是进程恢复，后台整理继续后置；整个第 3 点尚未收口，实际结果见[验证报告](verification-report.md)。

## 触发与模型输入

生产 Runtime 调用 `proposeNextActionWithCompression`，OpenAI adapter 在冻结工具参数与引用、构造原输入后准备派生输入。旧模型默认桥接原 context 接口；旧 adapter 入口保持完整历史，不隐式启用压缩。

仅 PLAN、EXACT_TEXT、无附件、至少两个工具历史条目可进入压缩。历史 JSON 达到 64 KiB UTF-8，编码输入至少节省 4 KiB 和 10% 时才采用；否则保持完整输入。原输入仍须满足快照 1 MiB 限额，不能靠压缩绕过来源保存边界。含 `device.type_text` 的历史保持正文省略投影，不压缩；图片/文档继续原附件路径。

目标、system、工具目录、Skill、工具名、参数、知识引用和最近一条结果正文完整保留。较早且超过 4 KiB 的结果正文改为最多各 1024 UTF-8 字节的首尾原文片段，按 Unicode code point 切取；不拼接成完整正文，不生成新事实。派生 JSON 标注 ToolCall ID、内容 SHA-256、完整字节数、显式省略字节数和固定说明。缺口不能猜测，片段不能提升提交或验证结论；完整 Tool Ledger 与最终回读仍是原有权威入口。

替换只作用于 user 文本末尾的历史区，原前缀完整复制，避免目标中出现相同 JSON 时被全局替换。最近结果完整保留不代表保证压缩到任意模型 token 上限；本片以 UTF-8 编码体积为门禁，不声称 tokenizer 或推理能力验收。

## 来源、版本与事务

`AgentContextCompressionCandidate` 携带原输入、历史起始字符位置与实际派生输入。Room 等锁前编码深冻结，再按版本 1 算法重新生成并逐项比对；提交与读取都核对原历史和实时 Tool Ledger 的工具名、参数、完整结果、success、PASSED、executorVerified 和知识引用。待完成响应或来源漂移拒绝，不能静默压缩或遗漏未验证工具。

每 Run 压缩版本从 1 连续递增，最多 32 个，原输入编码 JSON 合计最多 16 MiB；原快照的 64 帧/16 MiB 限制继续独立生效。压缩源不会被淘汰或覆盖，同 Step 同源同派生内容幂等，换源、换普通输入或换派生内容拒绝。

实际发送快照、完整原输入和压缩版本同 Room 事务 ABORT 保存。快照的 nullable `compressionVersion` 有每 Run 唯一索引；压缩帧摘要用独立 domain 绑定该版本，来源摘要再绑定 Run、Step、版本、frame sequence、历史起点、原输入与实际帧摘要。读取双向逐帧核对来源，缺来源、重复版本、关联或摘要损坏拒绝读取与追加，不修复或删除证据。SHA-256 是损坏检测，不是防恶意数据库写者的签名。

来源、正文和派生内容仍位于应用私有 Room 明文边界。附件正文与鉴权配置不进入这些字段；本片没有增加专用加密、用户导出或全局业务秘密检测。

## 失败与兼容

capture 完整提交后才发送派生输入，发送前再次检查取消。写入、限额或来源校验失败时整笔事务回滚，旧输入与完整工具结果保留；Runtime 固定脱敏异常停止请求，不用未保存派生内容或悄悄发送完整输入绕过门禁。仍活动的同 Step 可以重试保存且不产生序号/版本空洞；Runtime 已失败的 Run 沿用原有显式重试策略，不自动重启或重放工具。

压缩计算与保存包含在原规划步骤和 Run 的单调预算内，不产生第二次模型请求或虚构 telemetry。总结仍只选择回复样式，最终可信结果仍来自完整 Tool Ledger；审批、提交验证、恢复资格和权限边界不改变。

Room 42→43 新建空压缩表，并为原快照增加 nullable 压缩版本与唯一索引。旧行版本为 null，继续使用原 v1 摘要，不改原 payload、Run/Step 或 Memory version。显式 Run 删除经快照外键级联清理来源；同 ID Run 更新仍用 `@Upsert` 保留帧。

## 验证边界

JVM 核对字节触发/收益、原前缀与最近结果、Unicode、拒绝错误来源及 adapter wire；Redmi 使用 UUID 数据库、真实双 Room 连接和手机 loopback。生产 Runtime 成功时核对来源先于第三次请求提交，失败时只保留前两次请求/旧输入和 PASSED 工具事实。重开证明持久化，不代表自然 LMK 恢复；固定模型响应也不代表真实模型在压缩后完成任务的质量验收。
